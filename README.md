🎯 Демо
Грати в Duikt Clicker https://dima-novostroinyi.github.io/Lab-3-js/
✨ Функції
Основний геймплей
Клік-механіка - заробляйте кредити кліками
Комбо-система - бонуси за швидкі кліки підряд
Везучі кліки - шанс отримати x10 кредитів
Автозбереження - прогрес зберігається в браузері

📈 Система апгрейдів
Click Power - збільшує кредити за клік
Auto Clicker - автоматичні кліки щосекунди
Passive Income - пасивний дохід кредитів
Combo Multiplier - збільшує бонус від комбо
Lucky Clicks - збільшує шанс везучих кліків

🎁 Бонусні функції
Кейси (5,000 кредитів) - випадкові нагороди
Колесо фортуни (10,000 кредитів) - крутіть колесо для призів
Престиж (1,000,000 кредитів) - скиньте прогрес за Duiktcoins

🎨 Система скінів
6 унікальних скінів для персоналізації
Купуйте за Duiktcoins
Змінюйте кольорову схему гри

🏆 Досягнення
First Click - зробіть перший клік
Millionaire - заробіть 1 мільйон кредитів
Click Master - зробіть 10,000 кліків
Combo King - досягніть 10x комбо
Lucky Star - отримайте 100 везучих кліків
First Prestige - виконайте перший престиж
Prestige Master - виконайте 10 престижів
Skin Collector - розблокуйте всі скіни

😈 Антибонуси
Вірус 🦠 - вимикає автоклікер на 10 секунд
Баг 🐛 - зменшує цінність кліків на 50% на 15 секунд
DDoS атака 🔴 - блокує весь дохід на 20 секунд

🛠 Встановлення
Вимоги
Node.js 16+
npm або yarn

Кроки встановлення
Клонуйте репозиторій
git clone https://github.com/yourusername/duikt-clicker.git
cd duikt-clicker

Встановіть залежності
npm install
# або
yarn install

🚀 Запуск
Режим розробки
npm run dev
# або
yarn dev
Відкрийте http://localhost:5173 у браузері
Збірка для продакшн
npm run build
# або
yarn build
Перегляд збірки
bashnpm run preview
# або
yarn preview

🎮 Ігровий процес
Початок гри
Клікайте на велику кнопку "CLICK ME!" для заробітку кредитів
Купуйте апгрейди для збільшення доходу
Розблоковуйте досягнення та отримуйте нагороди

Стратегії
Ранній етап: Фокусуйтесь на Click Power та Auto Clicker
Середній етап: Інвестуйте в Passive Income та Combo Multiplier
Пізній етап: Максимізуйте Lucky Clicks та готуйтесь до престижу

Престиж
Потрібно 1,000,000 кредитів
Скидає весь прогрес, але дає Duiktcoins
Duiktcoins дають постійний бонус до доходу
Використовуйте Duiktcoins для купівлі скінів

🔧 Технології
Frontend Framework: React 18.2.0
Build Tool: Vite 4.4.5
Styling: SCSS Modules
State Management: React Hooks (useState, useEffect)
Storage: IndexedDB (via custom hook)
Animation: CSS Animations & Transitions
